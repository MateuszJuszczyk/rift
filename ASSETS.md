# Assets

Component surfaces and state emblems are rendered with CSS. Interface glyphs come from `lucide-react` (ISC).

DM Sans and Manrope Latin variable fonts are self-hosted. SIL Open Font License files are included in `public/fonts/`.

Ambient sound is generated locally through Web Audio. No remote image, font or audio requests are required at runtime.

Hero: original artwork generated with the built-in image_gen tool. Source PNG: `public/images/muted-prism-hero.png`; runtime WebP (49 KB): `public/images/muted-prism-hero.webp`. Prompt: `HERO-PROMPT.md`. The Linear article and Cloudfide recruitment banner informed composition and visual hierarchy; their assets are not embedded.
